## Description

Format and copy supported LeetCode example inputs in the language selected in your editor.

LeetCase supports C++, Java and Python. Switch between original and formatted inputs, and double-click a declaration to copy it. Optional Color Mode adds syntax colors, while Unique names numbers variables across examples.

Formatting runs locally. Your example inputs and rendered editor code are not uploaded by the extension. Only your formatting preferences are saved locally. Unsupported values or signatures remain in their original form.

## Single purpose

Display and copy supported LeetCode example inputs as declarations in the selected editor language.

## storage justification

Saves three local preferences: Input formatting, Color Mode and Unique names. It does not store example inputs, editor code or a browsing-history log.

## Host access justification

Content scripts run only on leetcode.com and www.leetcode.com problem pages. They read example inputs, the selected language and rendered editor code to infer supported signatures, then display and copy formatted declarations. This processing stays on the device.

## Remote code

No. All executable code is bundled. The extension does not fetch remote code or data.
