# Contributing

LeetCase is an independent project built by VoidHub. Contributions are welcome
through pull requests on GitHub. Maintainers review each
pull request and decide whether to merge it. Opening a PR does not guarantee a merge.

Keep changes focused on the current development stage. Explain the behavior,
include reproduction and verification steps, and avoid unrelated changes.
Do not change LeetCode's original testcase values or execution behavior.
